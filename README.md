# VANSHVERSE — Vansh Kaushik

Interactive portfolio for Vansh Kaushik (Software Development Engineer / Python Backend Developer).

- `/` boot screen
- `/explore` illustrated world

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment

Copy `.env.example` if you want the contact form live:

```
NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY=
```

The form uses [Web3Forms](https://web3forms.com). Without this key, visitors can still use email, LinkedIn, GitHub, and phone.

## Deploy to Vercel

The Phaser world runs entirely in the browser. No game server is required.

```bash
npx vercel
```
